## Overview

**MedSync SL** is a software solution designed to digitize patient registration, prescription tracking, and pharmacy inventory management for public healthcare institutions, specifically targeting operational bottlenecks observed at **Connaught Hospital** in Freetown, Sierra Leone.

This repository contains the **Phase 1 Dart Console Prototype**, which implements the core Object-Oriented Programming (OOP) logic and state management required for future mobile and database integration.

---

## System Features

 **Patient Registration:** Register new outpatients with unique system-generated IDs (`P001`, `P002`, etc.).
 **Pharmacy Inventory Tracking:** Manage available stock and prices for hospital medications.
 **Prescription Management:** Issue structured prescriptions linking registered patients to inventory items.
 **Automated Stock Deduction:** Real-time stock reduction upon drug dispensation with built-in stock availability validation.
 **Operational Dashboard:** Generate real-time system summaries of patients, inventory levels, and pending/dispensed prescriptions.
